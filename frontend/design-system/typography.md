# Typography

## Type Scale

| Token        | Size  | Line Height | Weight | Usage                           |
|--------------|-------|-------------|--------|---------------------------------|
| `text-display` | 32px | 1.2       | 600    | Hero sections, landing pages    |
| `text-h1`      | 28px | 1.25      | 600    | Page titles                     |
| `text-h2`      | 24px | 1.3       | 600    | Section headers                 |
| `text-h3`      | 20px | 1.35      | 600    | Card titles, KPI values         |
| `text-title`   | 18px | 1.4       | 600    | Brief values, emphasis          |
| `text-body`    | 15px | 1.6       | 400    | Body text, paragraphs           |
| `text-small`   | 13px | 1.4       | 500    | Navigation, buttons, labels     |
| `text-caption` | 12px | 1.4       | 400    | Secondary info, timestamps      |
| `text-micro`   | 11px | 1.3       | 500    | Badges, compact metadata        |

## Font Family

`'Encode Sans Semi Expanded'` — imported from Google Fonts.

## Rules

- Never use font sizes outside this scale.
- Never use font weights other than 400, 500, 600.
- `text-small` is the default for interactive elements.
- `text-caption` for metadata, dates, counts.
- `text-micro` only for space-constrained badges.
