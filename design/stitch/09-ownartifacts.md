# Stitch Prompt: OwnArtifacts

> Generate the artifact explorer module for Own Platform.
>
> **Context:** This prompt assumes `stitch/00-master-context.md` as the foundation. Read it first.
>
> **Priority:** Sprint 3

---

## Design Goal

Generate OwnArtifacts — the artifact explorer where users browse all immutable artifacts generated by the platform: evaluation reports, configuration snapshots, analytics reports, experiment results, learning records, and evidence findings.

OwnArtifacts is the system of record. It should feel like:

- **GitHub** — commit-like artifact cards, blame-like lineage view
- **Linear** — filterable, searchable list with quick preview
- **OSS Insight** — visual lineage graph

## Sections Detail

### Filter Chips
- **Content:** Horizontal chip row. "All" selected by default. Each chip shows count.
- **Interaction:** Click to filter by type. Multi-select. Active chips highlighted.

### Artifact Feed
- **Content:** Virtualized list of artifact cards. Each card shows: icon, name, summary, timestamp, action buttons.
- **Interaction:** Click card → detail. "Copy ID" copies full artifact UUID. "Show lineage" scrolls to lineage section.
- **Empty:** "No artifacts found. Try adjusting filters."

### Metadata Panel (Detail)
- **Content:** Key-value metadata: ID, type, version, timestamp, lineage reference, size.
- **Interaction:** Copy any field. Click lineage IDs → navigate to parent/child artifact.

### Content Preview (Detail)
- **Content:** Rendered artifact content. JSON/YAML shown in syntax-highlighted code block. Markdown rendered. Binary shown as metadata only with download link.
- **Actions:** Download raw, copy to clipboard, expand/collapse sections.

### Lineage Graph (Detail)
- **Content:** Interactive graph showing artifact lineage (parents → this → children). Clickable nodes navigate to that artifact.
- **Empty (no lineage):** "This artifact has no lineage recorded."
