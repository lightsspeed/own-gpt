# Product Vision

## One Sentence

An AI-native engineering platform where engineers investigate, understand, and improve AI systems through conversation — with every answer grounded in immutable evidence and every change governed by human approval.

## The Core Insight

AI systems are the most opaque software ever built. Traditional dashboards and logs cannot explain *why* a model behaves the way it does. Engineers need an interface that can reason across telemetry, evidence, experiments, and configuration — and explain its reasoning in terms they can verify.

That interface is conversation, augmented by a deep operations console for power users.

## What We're Building

A platform with two complementary interfaces:

1. **The AI Assistant** — The primary interface. Engineers ask questions, investigate failures, compare experiments, and plan changes through natural conversation. Every answer is grounded in platform artifacts with traceable lineage.

2. **The Operations Console** — The power user interface. Engineers inspect findings in bulk, compare experiment results side-by-side, audit configuration history, and manage automation schedules. The console is for depth; the assistant is for velocity.

## What Makes This Different

- **Not a chatbot** — Every response is grounded in evidence, not LLM hallucination
- **Not a dashboard** — The platform explains itself rather than requiring the engineer to correlate data manually
- **Not a CLI** — Engineers interact through natural language, not API calls or query languages
- **Not autonomous** — The platform recommends; humans decide. Every production change requires explicit approval

## Long-Term Ambition

Become the standard interface for operating AI systems in production — the way GitHub became the standard interface for collaborating on code, and Grafana became the standard for visualizing metrics.
